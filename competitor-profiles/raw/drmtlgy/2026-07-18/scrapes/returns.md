# DRMTLGY return-policy snapshot

- Source: https://www.drmtlgy.com/pages/return-policy
- Retrieved: 2026-07-18
- Window: contact DRMTLGY before 60 days from purchase.
- Tried products: customer returns the unused portion for a refund to the original payment method.
- Deductions: original shipping is not refunded; missing gifts are deducted.
- Process: RMA required and return must be postmarked within two weeks of receiving it.
- Scope: purchases made directly from DRMTLGY.com; selected mystery boxes are final sale.
- Limits: return activity is monitored and returns may be limited for abuse.
